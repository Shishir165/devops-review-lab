### Multi-Factor Authentication (MFA)

Multi-Factor Authentication (MFA) has been enabled for all IAM users to enhance account security.

**Process:**
1. Navigate to IAM → Users.
2. Select the IAM user.
3. Open the **Security credentials** tab.
4. Under **Multi-factor authentication (MFA)**, choose **Assign MFA device**.
5. Select **Authenticator app**.
6. Scan the QR code using an authenticator application (Google Authenticator / Authy).
7. Enter two consecutive one-time passcodes generated by the app.
8. Complete the setup.

MFA is enabled for all users in compliance with AWS security best practices.
